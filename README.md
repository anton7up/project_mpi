# Параллельные вычисления с MPI

## 📋 О проекте

Данный проект демонстрирует эффективность параллельных вычислений с использованием MPI (Message Passing Interface) на примере двух задач:
1. Вычисление числа π методом Монте-Карло
2. Умножение матрицы на вектор с различными схемами распределения данных
